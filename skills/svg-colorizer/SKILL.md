# SVGカラー化

線画セルを外注で彩色してもらったときに返ってくる**3つの形**を、どれも
`<g id="FILL">` ＋ `<g id="LINE">` の色面SVGに揃えるためのスキル。

```
[GPT等]  線画セル → 彩色 → 納品(下の3形態のどれか)
[こちら] ベクター化 / 線画復元 / 色味統一 → FILL+LINE の色面SVG → 漫画に組む
```

## 納品の3形態と対処

| 納品の形 | 症状 | 使うスクリプト |
|---|---|---|
| **PNGを埋め込んだだけのSVG** | 拡張子はSVGだが中身はラスタ。拡大すると眠い | `raster_to_fill_svg.py` |
| 白背景のPNG | 背景が不透明。コマに置くと白い箱になる | `raster_to_fill_svg.py`（同じ） |
| **色面だけで線画が無いSVG** | 輪郭が白く抜けて見える。目と口だけ黒パスがある | `color_line_merge.py` |

## 1. PNG内包SVG → FILL SVG

```bash
python3 scripts/raster_to_fill_svg.py <in.svg|in.png|dir> <out.svg|dir> --colors 20
```

やること:
1. 埋め込みPNGを取り出す
2. **外周につながる白**だけ透明にする（キャラの中の白は残す。装束や靴下が白いので、
   白を一律に抜くと体に穴が空く）
3. 絵の外形でタイトに切り抜く
4. **線画と色面を分けて起こす**
5. 色数を落として `colormode="color"` でトレース、線は二値でトレースして最前面へ
6. 色面どうしの隙間を、fillと同色のstrokeで塞ぐ

**ディレクトリを渡すと全カットから共通パレットを1つ作って使い回す。**
1枚ずつ減色すると同じ髪や袴がカットごとに違う色に丸められ、並べたときに色味が
揃わない。カットごとに最適化したいときだけ `--per-file`。

## 2. 色面だけのSVG → 線画を戻す

```bash
python3 scripts/color_line_merge.py <彩色dir> <線画dir> <出力dir>
```

色面は線画をなぞり直したもので、**セルごとに数pxずれている**（方向もバラバラなので
一括補正はできない）。セル単位で最適な平行移動を総当たりで求め、シルエットで
クリップしてから線画を最前面に戻す。はみ出し率20%超のセルは彩色側が別の形に
描き直しているので、平行移動では合わない＝発注し直し。

## 3. 色面の隙間を塞ぐ

```bash
python3 scripts/fix_hairline_gaps.py <in.svg|dir> <out.svg|dir> --width 2
```

`fill` と同色の `stroke` が `stroke-width="0"` で入っている納品SVG向け。
縮小表示では見えないが、コマに大きく敷くと白い罅が全面に出る。

## 踏んだ罠（同じ穴に落ちないこと）

- **線を残したまま減色すると輪郭が茶色くにじむ。** 細い黒線が中間色に潰れるため。
  色面側からは線を消し（まわりの塗りで埋め）、線は別に二値でトレースして重ねる
- **「暗い画素＝線」で判定すると赤い袴まで真っ黒になる。** 暗さだけでなく彩度も見て
  「暗くて色みが無い画素」を線とする
- **元PNGを拡大してからトレースしても良くならない。** パスが増えるだけ
  （実測: ×2で7MB、等倍で0.4〜1.4MB）
- **vtracerは指定した色をそのまま使わない。** 面ごとに色を作り直すので、20色に
  落としても出力は698色になる。出力の塗り色をパレットに吸着させる後処理が要る
- **色の距離計算をint16でやると桁あふれする。** `(0-255)^2` が負になり、白が赤に
  吸着するなど色が入れ替わる。int32で計算すること
- **減色でパレットを保つときはP modeのまま扱う。** RGBAに変換するとパレットが消え、
  ファイルが2.5倍に膨らむ
- 色数は20が目安。12まで落とすと瞳と肌の陰が潰れる

## 検品

- 出力の色数を数えて、全カットに共通する色がどれだけあるか見る
  （揃っていれば「8枚で20色・うち9色は全カット共通」のようになる）
- 背景の上に置いて白い箱が出ないか（透過できているか）
- 拡大して色面の隙間（白い罅）が出ないか

## 発注側への注意

彩色を頼むときは **「画像の縦横比とキャラの位置を変えないこと」** を明示する。
リサイズや余白の追加をされると、漫画に組んだときに立ち位置がずれる。
線画も一緒に出してもらえるなら、`color_line_merge.py` の工程が要らなくなる。
