# 九尾の焔は記憶を喰う — SVG漫画版（全6話・61ページ）

ネーム全集（CryptoNinja 42冊コマ割りビューア）の宇迦編を、`characters/015_uka/` の
SVG素材で実ページに起こしたものです。ダークファンタジー。

| 話 | 題 | ページ |
|---|---|---|
| ep1 | 初午の夜 | 9 |
| ep2 | 封印の綻び | 10 |
| ep3 | 兎と狐 | 10 |
| ep4 | 根の国の淵 | 9 |
| ep5 | 九尾 | 10 |
| ep6 | 名を呼ぶ声 | 13 |

各話に `name/`（ページごとのネームJSON）、`page/`（レンダ結果PNG）、
`contact.png`（右綴じ＝P1が右上のコンタクトシート）が入っています。

## 背景の入れ方

少年漫画の配分に寄せています。全コマに背景を敷くと画面が重くなって
セリフが読みにくくなるため、コマの役割で使い分けます。

| | 使いどころ | 実際の配分 |
|---|---|---|
| 実景背景 | ページ頭・場面転換・引きの絵 | 46コマ（26%） |
| 効果背景 | 感情の頂点、決めゴマ（集中線・フラッシュ・縦線・キラキラ・炎） | 45コマ（26%） |
| 白地 | 会話・寄り・リアクション・モノローグ | 83コマ（48%） |

全174コマ。効果背景のうち「回想のぼかし枠(BG094)」は横長コマに敷くと
枠線だけが波打って読めないので、記憶が消えるページは白地にしています。

背景素材の一部（BG046/048/053/055/056/057/059/060/079）は絵の中にID文字が
焼き込まれたままなので使っていません。使うなら先にラベルを消す必要があります。

## 作り直し方

ネームは `tools/build_uka_manga.py` が生成します（全話ぶんのコマ構成が
このスクリプトに入っています）。コマを差し替えるならスクリプトを直して再生成、
1ページだけ直すなら `name/pNN.json` を直接編集してください。

```bash
python3 tools/build_uka_manga.py 出力先        # ネームJSONを生成
# レンダは manga/svg/uka_ep1 と同じ手順（vectors_svg / vectors_expr / vectors_bg / sfx_lib を用意）
python3 render.py name/p01.json p01.svg
python3 -c "import cairosvg;cairosvg.svg2png(url='p01.svg',write_to='p01.png',output_width=760,background_color='white')"
```

## 表情の使い分け

顔の芝居は45枚の表情セルで撮っています。1コマだけなら `expr_id`（例 `EXP018`）、
感情の推移を3コマ続けるなら `beat_id`（例 `BEAT09`＝落胆の3連）を指定します。
`beat_id` は3コマに自動展開されるので、レイアウトは「2段ビート下」「3段ビート中」を使います。

初版はこの45枚をひとつも使わず、目のアップ2種（P086_front 15回・P085_front 11回）で
顔を回していたため、同じ表情が何度も出ていました。現在は26コマを表情セル17種に置き換え、
第二話P9（決意の3連）と第六話P4（落胆の3連）はビートで組んでいます。

足りない表情の一覧と追加発注の仕様は `docs/表情追加発注_宇迦.md` にあります。

## この版での割り切り

- **登場人物は全員ウカのセルで代用**しています。姉イズナ・於兎・岩爺の素材が
  同じ絵柄で存在しないため、2人コマ（P071〜P082）は「ウカ2体」です。
  会話の相手が誰なのかはセリフで読ませる作りになっています。
- 白玉・玄（狐二匹）、影狐の群れ、根の国の巨大な気配などの素材は無いので、
  該当コマは人物の芝居と効果背景に置き換えました。赤い単眼は BG093（黒ベタ+目）です。
- 原作ネームの見開き（第三話P5-6、第四話P4-5、第五話P6-7・P9-10 など）は
  単ページの1コマ大ゴマに畳んでいます。
- レンダラにナレーション枠が無いため、モノローグ・キャプションは
  角丸のフキダシで表現しています。
