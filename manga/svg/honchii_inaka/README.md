# 田舎のほんチい（テスト・全4ページ・フルカラー）

ほんチいとイズナの素材が使えるか確かめるための短編です。**カラー版の通し確認**を
兼ねていて、キャラも背景もすべて着色済みの素材で組んでいます。

- キャラ：ほんチい（`characters/honchii/poses`）、イズナ（`characters/037_izuna/poses`）
- 背景：本山町4点（棚田・吉野川・町並み・山道）を `BG101`〜`BG104` として登録
- レンダラ：`tools/render_page.py`（アイライン合わせ・白フチ込み）

## 確認できたこと

| | 結果 |
|---|---|
| カラーセルの合成 | 背景の上に正しく乗る。白い矩形で背景を覆う問題は出ない |
| 白フチ | カラー同士でも効く。写実寄りの背景でもキャラが読める |
| アイライン合わせ | 背景の地平線0.40を登録すれば、キャラが地面に立って見える |
| 2キャラ混在 | `chars` の `char` 指定で別キャラを同じコマに置ける（ほんチい＋イズナ） |
| 頭身差 | ほんチい3.5頭身とイズナ8頭身。`scale` 0.62 対 0.95 で並べると自然に見える |

## 素材側の作業

ほんチいはシート（1枚15カット）で納品されたので、`tools/slice_color_sheet.py` で
75カットに切り出しました。ベクターのまま切るので色が保たれます。

```bash
python3 tools/slice_color_sheet.py <sheet.svg> <ids.json> 3 5 <出力先>
```

キャンバス全面の白パス（`BACKGROUND` グループ）は切り出し時に捨てています。
残すとコマの背景を白い長方形が覆います。通し番号も、絵から離れた小さいパスとして落としています。

## この版の限界

- ほんチいは **75/450**、イズナは **15/450** しかないので、使えるポーズは
  直立・腕組み・腰に手・歩く程度です。話らしい話にはまだ足りません。
- 表情セルが両キャラとも無いので、顔の芝居は全身カットで代用しています。
- セリフのフキダシは白のままです。カラー版では背景に対してやや浮くので、
  フチや不透明度の調整を入れる余地があります。
