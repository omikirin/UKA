# フルカラー見本「まちぼうけ」（4ページ）

彩色済みのウカ素材だけで組んだ見本です。

| 使った素材 | 数 |
|---|---|
| `characters/015_uka/expr_color_line/` の表情セル | 13/15（EXP005・EXP006は彩色が線画と別形なので不使用） |
| P001 の front / side / back（彩色版） | 3 |

彩色素材が表情13＋全身3しかないので、**表情の3連ビートで話を運ぶ構成**にしてあります。
`expressions.json` の BEAT01-05（泣き／驚き／照れ／怒り／じわ笑い）がそのまま
起承転結になるので、素材の少なさが構成の制約として効いています。

背景は線画のままです。キャラだけ彩色なので、**背景もカラー化するか、
背景を薄いグレーに落とす**と馴染みます（現状は少年漫画の「キャラだけ強い」寄り）。

```bash
python3 tools/build_color_sample.py <出力dir>   # ネームJSONを生成
python3 tools/render_page.py <ネーム.json> <out.svg>
```

レンダには彩色セルを `vectors_expr` / `vectors_svg` に置いた作業ディレクトリが要ります。
彩色セルは白い下敷きが不透明なままだと背景の上で白い箱になるので、
外周につながる白を透過に落としてから使ってください。
