# 見本「セーターの季節」（7ページ）

`characters/sweater_girl/poses/` の555セル（C001-C555）で組んだ見本です。

- 前半 C001-C300 … **バストアップの表情カットが約90枚**。寄りのコマはここから
- 後半 C301-C555 … **男性キャラと二人のカットが約100枚**

```bash
python3 tools/build_sweater_girl_sample.py <出力dir>   # ネームJSONを生成
python3 tools/render_page.py <ネーム.json> <out.svg>
```

## 背景を重ねないカットがある

大学の門・書架・机・階段・ベンチなどが**絵の中にすでに描かれている**カットに
辞書の背景を重ねると、線が二重になって「背景が透けている」ように見えます。
`poses.json` の `has_bg` が true のグループには `background_id` を付けないでください。

## 出力解像度

ページPNGは**縦2600px**で書き出しています。1600pxだと線が潰れて眠く見えました。

## 気づいたこと

- 二人のカットは**男性が左・女性が右**で固定。右綴じで読むと視線は右から入るので、
  彼女から読ませたいコマはそのままで噛み合います
- フカン（C511-C525）は頭が大きく描かれていて、引きのコマに置くと身長が揃いません
- ベタのシルエット（C446-C450）は場面転換の入りに効きます
