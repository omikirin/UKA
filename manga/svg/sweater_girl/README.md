# 見本「うちの先輩は強い」（7ページ）

`characters/sweater_girl/poses/` の255セルだけで組んだ見本です。

この素材は**男性キャラと二人のカットが約100枚**あるのが強みなので、
「二人の関係」を軸にした話にしてあります。表情セルが無いかわりに
**顔のアップ（C421-C435）と手のアップ（C411-C420）**が用意されているので、
寄りのコマはそちらで作りました。

```bash
python3 tools/build_sweater_girl_sample.py <出力dir>   # ネームJSONを生成
python3 tools/render_page.py <ネーム.json> <out.svg>
```

## 背景を重ねないカットがある

大学の門・書架・机・階段・ベンチなどが**絵の中にすでに描かれている**カットに
辞書の背景を重ねると、線が二重になって「背景が透けている」ように見えます。
`poses.json` の `has_bg` が true のグループには `background_id` を付けないでください。

## 出力解像度

ページPNGは**縦2600px**で書き出しています。1600pxだと線が潰れて眠く見えました。
セル側の線は元シートと画素照合して中央値0.00%の一致なので、
線がきれいに見えないときは**セルではなく出力解像度**を疑ってください。

## 気づいたこと

- 二人のカットは**男性が左・女性が右**に固定で描かれています。右綴じで読むと
  視線は右から入るので、彼女から読ませたいコマはそのままで噛み合います
- フカン（C511-C525）は頭が大きく描かれていて、引きのコマに置くと
  他のカットと身長が揃いません。同じページに混ぜるときは注意
- C446-C450 のベタのシルエットは、場面転換や回想の入りに効きます
