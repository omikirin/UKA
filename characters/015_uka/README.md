# ウカ SVG素材ライブラリ（CryptoNinja #015 宇迦）

SVG漫画メーカー（svg-manga-maker スキル）用のキャラクターセル一式です。
線画をそのままベクター化し、**白いシルエットの下敷きを最下層に焼き込んである**ので、
背景SVGの上にそのまま重ねるだけで背景に負けません（重ね順の管理が不要）。

| ディレクトリ | 中身 | 命名 |
|---|---|---|
| `poses/` | 基本ポーズ90種 × 5アングル（正面/横/後ろ/アオリ/フカン）= 450 | `P###_front.svg` など |
| `expr/`  | 3連ビート15種 × 3ステップ = 45表情（正面） | `EXP###.svg`（001-045） |
| `expr_side/` | 追加ビート15種 × 3ステップ = 45表情（横顔） | `EXP###.svg`（046-090） |
| `expr_tq/`   | 同上（斜め45度） | `EXP###.svg`（046-090） |
| `expr_color/` | EXP001-015のフルカラー版（納品SVGそのまま。線画なし） | `EXP###.svg` |
| `expr_color_line/` | 同上に線画を戻し、色のずれを詰めたもの **使うのはこちら** | `EXP###.svg` |
| `_qc/`   | 検品用オーバービュー（ID名ラベル付き）とサンプルページ | PNG |

IDの意味は skill 側の辞書（`poses.json` / `expressions.json`）に対応します。
ネームJSONからは `pose_id` / `beat_id` で参照します。

## 使い方

```bash
# 作業ディレクトリに素材をリンクしてからレンダ
ln -s <このリポジトリ>/characters/015_uka/poses vectors_svg
ln -s <このリポジトリ>/characters/015_uka/expr  vectors_expr
python3 render.py ネーム.json page.svg
```

`_qc/sample_page.png` は実際にこの素材でレンダした1ページです。

## 素材の作り直し方

元データは発注シートPNG（3行×5列で15カット／枚。ポーズ30枚 + 表情3枚）です。
リポジトリ直下の `1.zip` `2.zip`（ポーズ001-450）と `3.zip`（表情001-045）が原本。

```bash
python3 tools/sheet_extract.py <sheet.png> <ids.json> 3 5 <出力先> <一時dir>
python3 tools/sheet_qc.py <出力先>          # 通し番号の消し残りを機械検品
python3 <skill>/scripts/masker.py <出力先> <マスク済み出力先>
python3 <skill>/scripts/svg_shrink.py <マスク済み> <最終>
```

`ids.json` はシート内の読み順（左上から右へ）に並べたIDの配列です。
作業解像度は元PNGの約3倍（`TARGET_W=4600`）。元画像以上の情報は増えないので、
これ以上上げてもファイルが重くなるだけでした（×6で4倍の容量、見た目は同等）。

## 検品済みの状態

- 通し番号ラベルの残存: ポーズ450/表情45+90とも 0件（`tools/sheet_qc.py` で検出）
- 追加表情90セルの線の欠落: 横顔 平均0.27%・斜め 平均0.43%（既存45セルと同水準）
- **線の欠落: 平均0.27%・最大1.05%**（`tools/check_lines.py` で元シートと画素照合）
- 白マスクの透け（マゼンタ地で測定）: 抽出サンプル60セルすべて 5%未満
- 全495セルを目視オーバービュー（`_qc/`）で確認済み

### 線の欠落について

初版はファイルを軽くするためトレースを簡略化していて、目の輪郭や耳の内側の毛など
細い線が**平均8.65%・最悪20%も飛んでいました**。`tools/check_lines.py` は元シートの
二値画像と出力SVGのラスタを画素単位で突き合わせ、「元にあって出力に無いインク」の
割合を出します。設定を細く取り直して0.27%まで下げたのが現在の版です。
1セル37KB→53KBに増えましたが、線の欠落は容量では取り返せません。

元シートの時点で目や口が欠けているセルは、`tools/part_graft.py` で
別セルからパーツだけ切り出して移植できます（座標は0-1の相対指定）。

汗マークや効果線など、キャラ本体から離れた小さな描き込みは
番号と紛らわしいため一部が除去されています（P030系の飛び散り等）。
必要になったらそのセルだけ元シートから切り直してください。

## 彩色セルの扱い

外注から返ってくる彩色SVGは**色面だけで線画が入っていません**。輪郭が線として
描かれていないので、色面の境目が白く抜けて「線が白い」ように見えます
（目と口だけ黒パスで入っていることが多い）。
さらに色面は線画をなぞり直したもので、元の線画と数pxずれています。

`tools/color_line_merge.py` が、色面を線画に合わせて平行移動し、
キャラのシルエットでクリップしてから、元の線画を最前面に戻します。

```bash
python3 tools/color_line_merge.py <彩色dir> <線画dir> <出力dir>
```

EXP001-015での結果: 13セルははみ出し2〜5%（縁に白下敷きが覗く程度）。
**EXP005とEXP006は26%・33%**で、平行移動では合いません。
彩色側が頭や耳を別の形に描き直しているので、この2枚は彩色し直しが必要です。
