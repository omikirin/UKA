# ウカ SVG素材ライブラリ（CryptoNinja #015 宇迦）

SVG漫画メーカー（svg-manga-maker スキル）用のキャラクターセル一式です。
線画をそのままベクター化し、**白いシルエットの下敷きを最下層に焼き込んである**ので、
背景SVGの上にそのまま重ねるだけで背景に負けません（重ね順の管理が不要）。

| ディレクトリ | 中身 | 命名 |
|---|---|---|
| `poses/` | 基本ポーズ90種 × 5アングル（正面/横/後ろ/アオリ/フカン）= 450 | `P###_front.svg` など |
| `expr/`  | よしながふみ式3連ビート15種 × 3ステップ = 45表情 | `EXP###.svg` |
| `_qc/`   | 検品用オーバービュー（ID名ラベル付き）とサンプルページ | PNG |

IDの意味は skill 側の辞書（`poses.json` / `expressions.json`）に対応します。
ネームJSONからは `pose_id` / `beat_id` で参照します。

## 使い方

```bash
# 作業ディレクトリに素材をリンクしてからレンダ
ln -s <このリポジトリ>/characters/015_uka/poses vectors_svg
ln -s <このリポジトリ>/characters/015_uka/expr  vectors_expr
python3 render.py ネーム.json page.svg
```

`_qc/sample_page.png` は実際にこの素材でレンダした1ページです。

## 素材の作り直し方

元データは発注シートPNG（3行×5列で15カット／枚。ポーズ30枚 + 表情3枚）です。
リポジトリ直下の `1.zip` `2.zip`（ポーズ001-450）と `3.zip`（表情001-045）が原本。

```bash
python3 tools/sheet_extract.py <sheet.png> <ids.json> 3 5 <出力先> <一時dir>
python3 tools/sheet_qc.py <出力先>          # 通し番号の消し残りを機械検品
python3 <skill>/scripts/masker.py <出力先> <マスク済み出力先>
python3 <skill>/scripts/svg_shrink.py <マスク済み> <最終>
```

`ids.json` はシート内の読み順（左上から右へ）に並べたIDの配列です。
作業解像度は元PNGの約3倍（`TARGET_W=4600`）。元画像以上の情報は増えないので、
これ以上上げてもファイルが重くなるだけでした（×6で4倍の容量、見た目は同等）。

## 検品済みの状態

- 通し番号ラベルの残存: ポーズ450/表情45とも 0件（`tools/sheet_qc.py` で検出）
- 白マスクの透け（市松ではなくマゼンタ地で測定）: 抽出サンプル60セルすべて 5%未満
- 全495セルを目視オーバービュー（`_qc/`）で確認済み

汗マークや効果線など、キャラ本体から離れた小さな描き込みは
番号と紛らわしいため一部が除去されています（P030系の飛び散り等）。
必要になったらそのセルだけ元シートから切り直してください。
