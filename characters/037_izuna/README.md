# イズナ（CryptoNinja #037・甲賀）セル素材

| ディレクトリ | 中身 | 命名 |
|---|---|---|
| `poses/` | **彩色済み**ポーズ 15/450（P001〜P003 の5アングル） | `P###_front.svg` など |
| `poses_line/` | **線画**ポーズ 225/450（P046〜P090 の5アングル） | 同上 |

線画セルはウカと同じパイプライン（`tools/sheet_extract.py` → `masker.py` → `svg_shrink.py`）で
発注シートPNGから起こしたもので、白いシルエットの下敷きが焼き込んであります。

## 彩色セル（`poses/`）の検査結果

| 項目 | 結果 |
|---|---|
| 形式 | 本物のベクターSVG（`FILL` グループ＋線画グループ、1セル11パス） |
| 背景 | **透過済み**。白い矩形は入っていない（描画すると55〜61%が透過） |
| 切り抜き | キャラの外形でタイト。全身セルは高さ341で揃っている |
| 目線 | セル上端から **約0.175**（ウカは0.165）。ほぼ同じなので同じコマに混ぜても違和感なし |
| レンダラ | そのまま `vectors_svg` に置いて動作確認済み。白フチも効く |

**ウカと違って最初から透過なので、`color_cell.py convert` を通す必要がありません。**
彩色版のウカ（白背景・不透明のラスタ）より扱いやすい形で納品されています。

**要確認：005 / 010 / 015 が「しゃがみ姿勢」に見えます。** 辞書ではこの位置は
フカン（`high`＝見下ろしアングル）です。ウカのシートではフカンは「頭が大きく
体が詰まった立ち姿」で描かれていました。**別ポーズとして描かれたのか、
フカンのつもりなのかで扱いが変わります**ので、次の発注前に確認してください。

## ファイル名の対応

納品時の連番を、辞書のID（`poses.json`）に合わせて付け替えてあります。
連番 n は `P{(n-1)//5+1}` ＋ アングル `[front, side, back, low, high][(n-1)%5]` です。

| 納品 | このリポジトリ |
|---|---|
| `izuna_pose_001` 〜 `005` | `P001_front` / `P001_side` / `P001_back` / `P001_low` / `P001_high` |
| `izuna_pose_006` 〜 `010` | `P002_*`（同じ順） |
| `izuna_pose_011` 〜 `015` | `P003_*`（同じ順） |
| `izuna_pose_226` 〜 `230` | `P046_*`（同じ順） |
| `izuna_pose_446` 〜 `450` | `P090_*`（同じ順） |
