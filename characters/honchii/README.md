## 納品SVGに「隙間」があります（修正済み）

**縮小すると綺麗に見えますが、コマに大きく敷くと全面が白い罅だらけになります。**
写真を色面に起こす過程で、隣り合う色面がぴったり接しておらず、髪の毛ほどの隙間が
空いているためです。同梱のプレビューPNGは正常なので、SVG化のときに生じた欠陥です。

各パスが `fill` と同じ色の `stroke` を持ちながら `stroke-width="0"` だったので、
線幅を2にして色面を自分の色で膨らませ、隙間を閉じました。

```bash
python3 tools/fix_hairline_gaps.py <in.svg|dir> <out.svg|dir> --width 2
```

線幅3以上にすると細部が潰れて絵が眠くなります（実測）。
**次の納品でも同じ状態で来るはずなので、受け取ったらまずこれを通してください。**

## そのままでは漫画に組めません

**1. シートのままなので、1カットずつに切り分ける必要があります。**（対応済み）
現行の `tools/sheet_extract.py` はラスタを二値化してトレースする白黒線画専用で
使えないため、`tools/slice_color_sheet.py` を作りました。75カット切り出し済みです。

```bash
python3 tools/slice_color_sheet.py <sheet.svg> <ids.json> 3 5 <出力先>
```

セル内のパスは**bboxが接しているものどうしを束ね、いちばん大きい塊をキャラ本体**と
します。通し番号や隣カットの食い込みは別の塊になるので自然に落ちます。
最初は「最大パスのbbox外の小さいパスを番号とみなす」方式にしていたのですが、
色ごとにパスが分かれているこの素材では**頭の桜や顔まで巻き添えで消えました**。

**2. `BACKGROUND` グループがキャンバス全面の白いパスです。**
切り分けるときに必ず外してください。残すとコマの背景を白い長方形が覆います
（ウカのカラー版で踏んだのと同じ問題）。カットの番号もこの白パスに穴として
抜かれているので、番号の扱いも同時に決める必要があります。

**3. 背景がフルカラーの写実寄りイラストです。**
白黒線画の漫画には合いません。**カラー版の漫画で使う前提の素材**として扱ってください。
地平線0.40は `assets_manga/horizons.json` に登録すればアイライン合わせがそのまま効きます。

**4. 3.5頭身なので目線の比率がウカ・イズナと違います。**
`tools/render_page.py` の `EYE_AT`（全身0.23）はウカ実測値です。
ほんチいのセルができたら測り直して、キャラ別に持たせる必要があります。
