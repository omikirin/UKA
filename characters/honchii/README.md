# ほんチい ポーズシート・背景（制作中）

CryptoNinja の42キャラには含まれないオリジナルキャラ。3.5頭身のデフォルメ体型。

## 収録

| | 中身 |
|---|---|
| `sheets/` | ポーズ **001-075**（3行×5列＝15カット × 5シート）。着色SVG＋フラットPNG＋プレビュー |
| `backgrounds/` | 本山町の背景4点（棚田・吉野川・町並み・山道）。SVG＋プレビュー |
| `仕様書_納品時.md` | 納品時に添えられていたキャラ仕様・色指定 |

076-450 は継続予定と納品書にあります。

## 検査結果

| 項目 | 結果 |
|---|---|
| 形式 | 本物のベクターSVG。色別グループ（SKIN / HAIR / COLLAR / OBI / FLOWER / KIMONO / LINE ほか） |
| シート | 1536×1024 に15カット。番号は各カットの左上、絵から離れている |
| 背景 | 1536×1024。**地平線は約0.40**（納品仕様どおり。実測でも一致） |
| 容量 | シート1枚 約3MB（19,729パス）、背景1枚 26,000〜34,000パス |

## そのままでは漫画に組めません

**1. シートのままなので、1カットずつに切り分ける必要があります。**
現行の `tools/sheet_extract.py` はラスタを二値化してトレースする白黒線画専用で、
このカラーベクターには使えません。**ベクターのまま3行×5列に切り分ける道具が要ります**
（パスのbboxでグリッドに振り分け、fillを保ったまま15個のSVGに分ける）。作れます。

**2. `BACKGROUND` グループがキャンバス全面の白いパスです。**
切り分けるときに必ず外してください。残すとコマの背景を白い長方形が覆います
（ウカのカラー版で踏んだのと同じ問題）。カットの番号もこの白パスに穴として
抜かれているので、番号の扱いも同時に決める必要があります。

**3. 背景がフルカラーの写実寄りイラストです。**
白黒線画の漫画には合いません。**カラー版の漫画で使う前提の素材**として扱ってください。
地平線0.40は `assets_manga/horizons.json` に登録すればアイライン合わせがそのまま効きます。

**4. 3.5頭身なので目線の比率がウカ・イズナと違います。**
`tools/render_page.py` の `EYE_AT`（全身0.23）はウカ実測値です。
ほんチいのセルができたら測り直して、キャラ別に持たせる必要があります。
