# 漫画レンダ用の共有素材

`svg_manga_kit.zip` に入っていた背景とオノマトペを、リポジトリ側に展開したものです。
レンダラはこのディレクトリ名（`vectors_bg` / `sfx_lib`）をそのまま見ます。

| | 中身 |
|---|---|
| `vectors_bg/` | 背景105（実景85 + 効果背景15 + 予備） |
| `sfx_lib/` | 手描きオノマトペ100語 |

## 背景のIDラベルを消してあります

発注シートから切り出したままの背景10枚（BG041/046/048/050/053/055/056/057/059/060）は、
絵の左上に「BG046」というID文字が焼き込まれたままでした。`tools/bg_delabel.py` で消してあります。

```bash
python3 tools/bg_delabel.py strip vectors_bg/BG046.svg 出力.svg --box 0,0,0.34,0.18
```

**パスを削除するのではなく、地色の矩形を最前面に被せて隠しています。**
ID文字は背景の線画と重なって描かれているため、文字のパスだけを消そうとすると
背後の木や柵の線まで巻き添えになって絵が壊れます（実際に一度壊しました）。
被せる方式なら絵は無傷で、左上隅が平らになるだけです。BG057（星空）は黒地なので
パッチも黒を自動で選びます。

枠の自動検出（`scan`）も入れてありますが、線の密な絵を誤検出するので、
**枠は手で指定するのが確実**です。10枚とも `0,0,0.34,0.18` で足りました。

## オノマトペは辞書の100語だけを使うこと

レンダラは `sfx_lib/<語>.svg` を探し、無ければフォントをパス化して描きます。
つまり辞書外の語（「ドサッ」「ぴーひゃら」など）を書くと、
**手描きの描き文字素材が使われず、ただの文字**になります。
使える100語は `onomatopoeia.json` にあります。
