# こんとも撮影ツール

**`起動.command` をダブルクリック**すると開く。こんとも専用。

> `.html` を直接ダブルクリックしても動くが、`file://` だと設定の自動読み込みと
> 音声解析がブラウザに止められる。**`起動.command` を使うこと。**

## できること

### ポーズ・表情を選ぶ
- ポーズ4種（素立ち／腕組み／手振り／ハート）
- 表情8種（ふつう／半目／嬉しい／にっこり／目閉じ／泣き／点目／怒り）
- 口6種（ん・あ・い・う・え・お／猫口ω）
- 自動で目ぱち（1.8〜4.4秒のあいだにランダム）

### 文章を入れて喋らせる
テキスト欄に**ひらがな・カタカナ**で入力 →「喋る」。
かなを母音に変換して口を動かす。速さはスライダー。
漢字は変換できないので、かなで書くか、下の音声＋台本を使う。

### 音声で喋らせる
- **音声だけ選ぶ** … 音量に合わせて口が開閉する。準備ゼロ
- **音声＋タイミングJSON** … 母音まで正確に合う。先にこれを作る:

```sh
（faster-whisperとpykakasiを入れたPython） audio_to_vowels.py --audio 音声.wav --script 台本.txt --out cues.json
```

### 撮影する
- **背景**: 透過／生成りベージュ／白／黒／グリーンバック／自分で指定
- **サイズ**: そのまま／縦1080x1920／横1920x1080／正方1080x1080／アイコン512x512
- **寄り**: 全身／バストアップ／顔アップ
- **📷 いまの1枚を保存** … 表示中の状態をPNGで保存
- **全ポーズ×全表情を一括保存** … 32枚（4ポーズ×8表情）をまとめて保存

保存名は `こんとも_ポーズ_表情_口.png`。

## 素材を差し替えたら
`parts/` `parts_mouth/` `rig_params.json` を新しいものに置き換えてリロードするだけ。
位置合わせツールで直した `rig_params.json` はそのままここに入る。

## 中身
```
こんとも撮影ツール.html   本体
起動.command              ローカルサーバを立てて開く
rig_params.json           位置合わせの設定
parts/                    head_*.png（表情8） / body_*.png（ポーズ4）
parts_mouth/              mouth_*.png（猫口6）
audio_to_vowels.py        音声→母音タイミング（外部API不要）
```
