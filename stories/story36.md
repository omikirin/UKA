# 社カフェ、はじめました

　発端は、社の屋根だった。
「雨漏り三箇所。柱の傾き二寸。修繕費は、賽銭三十年分といったところか」
　長老の見立てに、稲荷の社を預かる宇迦は頭を抱えた。忍務の報酬は評定に納められ、社までは回ってこない。賽銭箱の中身は小銭が数枚と、なぜか松ぼっくりが三つ。
「潰すか直すか、二つに一つじゃな」
「直すに決まってるでしょう。あたしの社だ。……よし。商売だ」
「嫌な予感しかしないね」
　襟巻きのコンが言い終わる前に、宇迦は動いた。境内の掃除、縁台の設置、竈の増築。七日後、鳥居の脇に看板が立った。
　——社カフェ、こんこん堂。狐火焙煎の茶と、音羽屋仕入れの油揚げ茶漬けの店。
　これが、当たった。

　　　＊

　客の大半は里の忍びである。忍びの客というものは、注文が無理難題と相場が決まっていた。
「毒見済みの茶を三秒で出せ」
「裏口と抜け道のある席を頼む」
「眠気の覚める甘味を。ただし音を立てずに食えるものに限る」
「隣の席の話が聞こえない席はあるか」
「全席そうしてあります。忍びの店ですので」
　宇迦は狐火で応じた。湯呑みに毒があれば狐火が青く燃えるから毒見は一瞬。抜け道は社の床下に元から完備。甘味は音のしない水羊羹に、狐火で「喝」の一文字を焼き付けた。とどめに始めた狐火の泡絵——茶の湯気の上に狐火で九尾の絵を描く芸——が評判を呼び、こんこん堂は連日の大入りとなった。
　修繕費の貯まっていく帳面を眺め、宇迦がほくほくしていた矢先である。
　朝、社の御扉の前に、風もないのに書き置きが一枚、落ちていた。
　——騒がしゅうて敵わぬ。静けさを返せ。しばし出る。氏神。
「……家出だ」
　コンが呆れた声で言った。「御祭神が、家出なすった」
　その日から、里じゅうの護符の効きが目に見えて鈍った。社の力は氏神あってこそ。カフェで社を守るつもりが、カフェが社を空にしたのである。八方手を尽くした捜索の果て、氏神は商店通りの音羽屋の裏で、油揚げの端切れをもらう白い老狐の姿で発見された。

　　　＊

「帰ってくださいよ、氏神さま」
「断る。あの社はもう、茶屋じゃ」
　老狐はぷいと横を向いた。宇迦は言い返しかけて、やめた。思えばこの百年、社が静かだったのは、参る者が絶えていたからだ。賑わいを取り戻した引き換えに、祈りの場所を潰したのでは、あたしは何を守ったんだか——そこまで考えて、宇迦は頭を下げた。
「騒がせたのは謝ります。でも、店は潰しません。両方やります。あたしは欲張りなので」
　七日後、こんこん堂に新しい貼り紙が出た。
　——週に一度、夜の営業は休み。ただし灯りは点しておきます。
　その晩から、七日に一度、社は客のいない夜を迎える。縁台に品書きはなく、代わりに供え物の膳がひとつ。境内には狐火の灯籠だけが並び、賑わいの音は消え、灯りだけが御扉までの道を照らす。
　氏神はその夜だけ社に帰り、膳の油揚げを平らげ、朝までそこにいる。護符の効きは戻り、屋根の修繕は無事に済んだ。
　貼り紙の隅には、いつからか小さな字が書き足されている。筆跡の主は、誰も知らない。
　——茶屋も、まあ、悪うない。

（了）
