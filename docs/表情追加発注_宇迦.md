## なぜ同じ表情が続いて見えたのか

**45枚ある表情セルを、宇迦編6話ではひとつも使っていませんでした。** 私のネームの書き方の問題です。
顔の芝居を全部ポーズ側の寄りカットで処理していて、内訳はこうでした。

- `P086_front`（目のアップ・伏し目）… **15回**
- `P085_front`（目のアップ・見開き）… **11回**

この2枚で顔コマの大半を回していたので、同じ絵が何度も出ていました。
現在は26コマを表情セル17種に差し替え、2箇所は3連ビート（BEAT08 決意 / BEAT09 落胆）に置き換えてあります。

## 納品後の処理

```bash
python3 tools/sheet_extract.py uka_beats_04_046-060.png ids/beat_04.json 3 5 出力先 一時dir
python3 tools/sheet_qc.py 出力先              # 通し番号の消し残りを検出
python3 tools/check_lines.py crops 出力先     # 線の欠落を検出
python3 <skill>/scripts/masker.py 出力先 マスク済み
python3 <skill>/scripts/svg_shrink.py マスク済み characters/015_uka/expr
```

`ids/beat_04.json` は `["EXP046", …, "EXP060"]` のような読み順（左上から右へ）のID配列です。
辞書側（`expressions.json`）にも BEAT16-30 の定義を足す必要があります。

## ポーズ側で足りていないもの（参考）

表情シートとは別枠ですが、宇迦編で代用が効かず困ったカットも記録しておきます。

- **狐（白玉・玄）** … 相棒の狐2匹。全カットで人物の芝居に置き換えました。最優先で欲しい素材です。
- **群れの影**（目のない灰色の狐の群れ）… 第三話の戦闘が全部「効果背景＋主人公の芝居」になっています。
- **他キャラ**（イズナ・於兎・岩爺）… 2人コマは全部「ウカ2体」で代用中です。
