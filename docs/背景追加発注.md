# 背景の過不足 — 棚卸しと追加発注リスト

## 結論から

**100枚のうち46枚が現代・学園ものです。** 忍者時代劇42冊では一枚も使えません。
教室・廊下・体育館・コンビニ・ゲームセンター・電車内・ラボ・宇宙・コックピットなどです。

実際に使えるのは54枚。うち16枚は効果背景（集中線・フラッシュ等）なので、
**時代劇の実景として選べるのは実質38枚**しかありません。

宇迦編61ページを組んだときの内訳がこれです。

| | コマ数 |
|---|---|
| 白地 | 84（48%） |
| 効果背景 | 42（24%） |
| 実景背景 | 47（27%） |

白地48%は少年漫画の配分として妥当なので問題ありません。困ったのは**実景を入れたい
コマで手持ちに無く、別の場所で代用した**ぶんです。以下は宇迦編で実際に代用したものです。

| 描きたかった場所 | 代用した背景 | コマ数 |
|---|---|---|
| 夜の参道（灯籠に火が入っている） | BG066 鳥居の参道（昼想定） | 7 |
| 根の国の淵（黒い水の異界） | BG093 黒ベタ+目だけ | 6 |
| 囲炉裏端の奥座敷 | BG023 和室 | 5 |

## 発注プロンプト

既存の背景（`assets_manga/vectors_bg/BG043.svg` など）を**参照画像として添付**してください。
線の太さと密度が揃わないと、同じページに並べたときに背景だけ浮きます。

```
添付画像と同じ画風で、漫画用の背景素材シートを1枚作成してください。

【全体ルール】
・3行×5列＝15カット。各カットは横長（4:3）の背景画のみ。人物は一切描かない。
・黒一色の線画、白背景。ベタとトーンは使わない（漫画側で重ねるため）。
・添付の既存背景と同じ線の太さ・同じ描き込み量。細かすぎるとコマに敷いたとき潰れる。
・各カットの間に十分な余白をとる（枠線で仕切らない。接触・はみ出し厳禁）。
・通し番号は各カットの左上に、絵から離して小さく置く。
  ※番号は絵に重ねないこと。重なると素材化のときに絵ごと消すしかなくなる。
・時代は日本の戦国〜江戸期。近代的な要素（電線・看板文字・洋風建築）を入れない。
・600DPI相当の高解像度PNGで納品。

【各カットの内容】
（上の表の「背景」と「必須要素」を 001〜015 の形で貼る）
```

### 解像度について

既存背景は1枚あたり約870×630pxで納品されています。コマに敷くとやや粗いので、
**枚数を減らして1枚を大きく**したほうが仕上がりは良くなります。
2行×3列（6カット/シート）にすると1カットあたり4倍の情報量になります。
30枚なら5シートです。急がないならこちらを勧めます。

## 納品後の処理

```bash
python3 <skill>/scripts/bg_extract.py uka_bg_01.png 101   # 101番から連番で切り出し
python3 tools/bg_delabel.py scan 出力先                    # 番号の消し残りを確認
```

`backgrounds.json`（辞書）にも追記が必要です。`category` は
`和風` / `自然` / `バトル` / `演出` から選びます。レンダラは実素材が無い場合、
`category` が `演出` のものだけ手続き描画にフォールバックします。

## ついでに：既存背景の直したほうがいい点

- **BG066（鳥居の参道）は昼想定**です。夜の場面で使うと灯籠に火が入っていないので、
  夜バージョンがあると宇迦編・祭りの場面が全部よくなります。
- **BG095（モノローグの空白）は棒人間が描かれていて使えません。** 素材事故です。
  白地にしたいときは背景を指定しないほうが早いので、実質欠番として扱っています。
- **BG085（真っ白/真っ黒の心象空間）は丸が浮いているだけ**で心象空間に見えません。
- 上の3枚は作り直しの価値があります。
